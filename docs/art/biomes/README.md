# Biome art asset inventories

Durable inventories for every currently cataloged level, generated from actual level/story data. Each identifies shared source geometry, original procedural factories, UI/VFX/audio dependencies and remaining painted/rigged polish. Software desktop dressing captures are evidence of loading and appearance; complete authored gameplay and phone performance require their own reports.
