# Audio Quality Review: 2026-10-14

> **Reviewer**: audio-director, acting as strict AAA audio critic
> **Bar**: `.claude/docs/reference-quality-bar.md`, Sound row: ">= 8/10, every action has feedback, music per biome". Tone reference: `design/art/art-bible.md` §1, "painted, chunky, toy-like storybook fantasy ... premium mobile puzzle game".
> **Design truth judged against**: `design/gdd/audio.md`, `design/gdd/audio/audio-direction.md`, `design/gdd/audio/sfx-cue-list.md`, `design/gdd/audio/music-sourcing.md`, `design/reviews/mockups/audio.md`, `docs/architecture/adr-0015-audio-feedback-pipeline.md` (status **Accepted**), `design/accessibility-requirements.md` §6.
> **Verdict**: **FAIL, 3/10 overall.** No category reaches 8. Audio is the weakest discipline in the game right now.

## 3. Top 15 instructions to the team

Owner tags: `audio-code` (gameplay or engine programmer, `src/`), `sfx-content` (sound-designer), `music-content` (composer, or the user supplies), `mix` (audio-director with sound-designer).

**Intake rule for every content instruction (6 to 12)**: each file brought in must have the following before it merges:
- a `credits.json` entry, and a dated licence screenshot in `assets/audio/licences/` (music-sourcing.md §2)
- the naming convention `[category]_[context]_[name]_[variant]`
- a 44.1 kHz source

CC0 only from the Kenney, Freesound and OpenGameArt pages linked in §4. Confirm the licence **on the asset page**, never from a search snippet. On Freesound, filter by "Creative Commons 0" and record the sound ID and author. Raw library files are **layers, not finished cues**. Every shipped cue is layered, trimmed, EQ'd into 700 Hz–4 kHz and levelled.

### 1. `audio-code`: build the bus graph and make the sliders real
- Add `default_bus_layout.tres`: Master (HardLimiter, ceiling -1.0 dB), Music (Compressor sidechained from SFX, then LowPass bypassed), SFX, UI, Ambience (Compressor sidechained from SFX, then LowPass bypassed). Use the default levels -6 / 0 / -3 / -12 dB from audio-direction §2.
- Set `.bus` on every `AudioStreamPlayer`. Nothing may play on Master.
- Sliders call `AudioServer.set_bus_volume_db(idx, linear_to_db(pct/100))`, and 0 % mutes the bus. Delete the per-player `- 7.0` and `- 12.0` offsets in `wt_audio.gd`.
- Wire the dead "UI clicks" slider to the UI bus. Add the Master slider (ACC-60 SHOULD).
- Accept: a unit test covers F1 (50 % gives -6.0 dB ±0.1). Each slider at 0 silences only its bus.

### 2. `audio-code`: implement the ADR-0015 cue registry with variation and priority
- Create `assets/data/audio/cues.json`, one row per `SFX_*` id with: files[], bus, dB, fixed_st, random_st, priority, max_voices, cooldown_ms, ducks_music_db.
- Build each cue as an `AudioStreamRandomizer` (random-no-repeat, `random_pitch` from `random_st`, `random_volume_offset_db` 1.0).
- Pools: SFX 12 (16 when 3–4 players), UI 4, Ambience 2. Steal the lowest priority first, then the oldest. Drop the same cue within 50 ms.
- Pitch comes from a presentation-only RNG.
- Accept: GDD acceptance criteria 2, 5 and 7 pass as gdUnit tests.

### 3. `audio-code`: wire every orphan and fix the substring bug (cheapest large win)
- Play `move` on `PIECE_MOVED`, a bonk on `PIECE_BLOCKED`, and `drop` when the lock cause is hard drop.
- Play `ui_star` with +0, +3 and +7 st at 300 ms spacing on the result screen.
- Play `ui_unlock` and `pack_fanfare` on unlock, and `stage_clear` through `jingle()` after `win`.
- Hook UI sounds: `ui_tap` via `node_added` on `BaseButton.pressed`, `ui_back` on cancel, `ui_toggle`, `ui_whoosh` on screen change.
- Call `WtMinigameAudio.sfx_for_data()` from `minigame_round`/`minigame_session` event fan-out.
- Use `party.wav` for tournament rounds. Use `wizard_sparkle` on the wizard story beats.
- **Replace** the `"wind" in kind` and `"flip" in kind` substring matching with an explicit event→cue table. Today, boss windups play the gust sound and gust warnings double-fire.
- Accept: a grep test asserts that every file in `assets/audio/**` is referenced by `cues.json` or `music.json` (no orphans).

### 4. `audio-code`: build the MusicDirector and MusicDeck
- Use one persistent music owner above the stage, not a `WtAudio` per stage, so the title, map and menus have music and the title track survives going from title to map.
- Resolve the level `music`, then the biome `default_music`, then `meadow`, through `assets/data/audio/music.json`.
- Run two decks with a 1.0 s equal-power crossfade that starts on the countdown.
- Use native loops: OGG `loop=true` with `loop_offset`, or WAV `loop_mode=1` with an end sample. Never replay on `finished`.
- Ducks are tweens on the **bus**, not on player volume: jingle -12 dB with 150 ms down and 400 ms up; flip -6 dB for 300 ms.
- Pause: LowPass 800 Hz and -6 dB over 0.2 s, with `TWEEN_PAUSE_PROCESS`. Danger: LowPass 2 kHz and -4 dB over 0.5 s in, 1.0 s out.
- Win and loss: fade 0.5 s, then the jingle.
- Accept: GDD acceptance criteria 6, 8, 9 and 10.

### 5. `audio-code`: make events scale and add the missing gameplay signals
- Clear: one cue per layer at `clear_stagger_ms` with the ripple pitch table +0, +2, +4, +7, +9, +12 st (F3). Then a tier cue `SFX_CLEAR_1..4` by layer count, with +0 to +3 dB from F2.
- Combo: +1 st per step, capped at +6.
- Turn, Flip and Roll: read the axis from `PIECE_ROTATED` and use offsets +5 / +2 / -1 st.
- Near-miss: a lock whose top cell sits at `h_play-1` and no top-out.
- Danger on and off (edge-triggered, 5 s cooldown). Countdown ticks and Go. Rescue.
- Mascot and boss `react()` emit a cue id. Item, skill and hold commands.
- Haptics: the setting exists and does nothing. Implement `Haptics` per audio-direction §8, or hide the setting.

### 9. `sfx-content`: characters, mascots and bosses (wordless, GDD rule 11)
- **Mascot emote set.** For each mascot, 7 emotes: exclaim, heart, gloom, sweat, dizzy, cheer, sparkle. Each is 200–600 ms, built from **instrument** voices: ocarina, kazoo, slide whistle, toy squeeze-horn, musical saw for "dizzy". Each mascot gets its own instrument so players learn who is reacting.
