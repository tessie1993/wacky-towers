# Original synthesized audio

The WAVs in `music/` and `sfx/` are original generated audio made for Wacky Towers.
Their reproducible source is `tools/asset-pipeline/generate_audio.py`; no samples,
recordings, external compositions or third-party audio assets are used.

Music is a small four-bar toy-instrument loop with per-biome register and timbre.
These are playable defaults that can be replaced with the user's final tracks.
Each file is mono PCM16 at 22.05 kHz. The ten loops total approximately 4.7 MB.
Audio settings independently control master, music and effect volume.
