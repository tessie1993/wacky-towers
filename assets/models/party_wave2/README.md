# Party wave-2 landmark toys (MG22-MG36)

Fifteen decorative landmark toys for the wave-2 party minigames
(`design/gdd/party-minigames-wave2.md`, acceptance criterion 7). Each toy sits on the
shared party base plate (radius 1.7, plate top at Godot Y=0) and carries only the
verb cue for its round. The runtime owns rules, pieces and collision.

## Source and rebuild

The source of truth is code, not a DCC file: `WtMinigameArt.create(id)` in
`src/view/wt_minigame_art.gd` builds every toy from Godot primitive meshes
(BoxMesh, CylinderMesh, SphereMesh, TorusMesh) with flat matte
StandardMaterial3D colours. The GLBs are a snapshot of that factory, so the runtime
and the exports cannot drift apart unless the factory changes without a re-export.

```sh
godot --headless --path . -s res://tools/art/export_party_wave2_models.gd
godot --headless --path . --import
```

The exporter uses `GLTFDocument.append_from_scene` + `write_to_filesystem`, fails
(exit 1) if any file is missing or over 400 KB, and rewrites `manifest.json` with
id, file, prop, triangle count, mesh count, bytes, SHA-256 and provenance.
Godot 4.7.2 produced the committed files.
